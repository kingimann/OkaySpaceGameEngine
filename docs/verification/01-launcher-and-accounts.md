# Verify: Launcher and accounts

The launcher (`OkaySpace.exe`): sign in, updates, settings, Create/Play pages, friends, store pages, crash reports.

Generated by `scripts/gen_verify_checklist.py` from the feature map and `docs/verification/steps/LA.md`; do not edit by hand. Read the [guide](README.md) first (legend and how to report).

Areas: 17, 25, 48, 49. Rows ids start `V-LA-`. `V-LA-S<area>` rows are smoke tests built from the map; `V-LA-NNN` rows have written steps.

- [ ] **V-LA-001** Start the launcher and switch pages
  - **Map:** 17.1.1. **Where:** `OkaySpace.exe`
  - **Steps:**
    1. Double-click `OkaySpace.exe`. A splash shows, then the launcher window with a sidebar.
    2. Click the sidebar entries **Create**, **Play**, **Community**, **Account** and **Settings** one after the other.
    3. Click in an empty part of the page (not in a text box) and press the number keys 1 to 5: they jump to the same five pages in that order.
  - **You should see (expected, not yet seen on Windows):** each page opens without a black frame or a crash; the number keys change the page.
  - **Known partial:** `launcher/main.cpp` is one 1.5 MB file with no automated UI test (map 17.1); the tray icon code is not used.

- [ ] **V-LA-002** Create an account
  - **Map:** 17.2.1, 17.2.5. **Where:** `OkaySpace.exe`, Account page
  - **Steps:**
    1. Open the **Account** page (not signed in).
    2. Switch to **Create account**. Fill **Username**, **Email** and **Password** (6 or more characters).
    3. Press **Create account**.
  - **You should see (expected, not yet seen on Windows):** the page changes to a signed-in profile and a "Signed in" notice; a taken username says "That username is taken".
  - **Known partial:** the Supabase path needs the live server and is not run in CI (map 17.2); use a throwaway account.

- [ ] **V-LA-003** Sign out and sign in again
  - **Map:** 17.2.5. **Where:** `OkaySpace.exe`, Account page
  - **Steps:**
    1. On the **Account** page press **Sign out**.
    2. Press **Sign in** and enter your **Email or username** and **Password**.
    3. Close and reopen the launcher.
  - **You should see (expected, not yet seen on Windows):** you are signed in again, and still signed in after the restart (the session is kept).
  - **Known partial:** "signed out after a restart" is a listed symptom in the map (17.2); report it if you see it.

- [ ] **V-LA-004** Password reset email
  - **Map:** 17.2.1. **Where:** `OkaySpace.exe`, Account page, signed out
  - **Steps:**
    1. On the **Account** page press **Forgot password?**.
    2. Enter your email and send.
    3. Open the link in the email.
  - **You should see (expected, not yet seen on Windows):** "Password reset email sent. Open the link in it to choose a new password." and a page where you pick a new password.
  - **Known partial:** the hosted reset page (`OKAY_PASSWORD_RESET_URL`) must be set up by the owner; without it the launcher says no reset page is set up.
  - **More:** [password-reset.md](../../password-reset.md)

- [ ] **V-LA-005** Check for updates by hand
  - **Map:** 17.1.2. **Where:** `OkaySpace.exe`, Settings page
  - **Steps:**
    1. Open **Settings** and find the About section (the version is shown there).
    2. Press **Check for updates**.
    3. Wait for the button to stop saying "Checking".
  - **You should see (expected, not yet seen on Windows):** a toast "You're up to date" when you are on the newest release, or "Update available" with an **Install now** button when not.
  - **Known partial:** the update index (`versions.json`) is not signed yet (map 17.1, 17.11).
  - **More:** [updater.md](../../updater.md)

- [ ] **V-LA-006** Update check when the launcher starts
  - **Map:** 17.1.2, 17.1.3. **Where:** `OkaySpace.exe`, Settings page
  - **Steps:**
    1. In **Settings** find **Check for updates when the launcher starts** and turn it on.
    2. Close the launcher and start it again; wait about 10 seconds (the first look is shortly after start, then every 5 minutes).
    3. Turn it off, restart, and wait again.
  - **You should see (expected, not yet seen on Windows):** with it on, a newer release raises the toast "Update available: OkaySpace v..." and a notification; with it off, nothing is checked until you press the button. If you are already current, nothing appears either way, so you need a release older than the newest one to see this.
  - **Known partial:** needs an older installed version to see a real result. Updates are opt-in by button (launcher comment near the periodic check).

- [ ] **V-LA-007** Install an update and restart
  - **Map:** 17.1.2. **Where:** `OkaySpace.exe`
  - **Needs:** an installed release older than the newest published one
  - **Steps:**
    1. When the sidebar shows **Install now** (or Settings shows it after a check), press it.
    2. Watch the progress; the launcher closes and starts again by itself.
    3. Open **Settings** and read the version.
  - **You should see (expected, not yet seen on Windows):** the version is the new one, the launcher started on its own, and `Tools\OkayEngine.exe` and `Tools\OkaySpacePlayer.exe` are updated too. A refusal (no checksum, antivirus lock) shows the reason in words and leaves your version unchanged; the reason is also in `okay_update.log` next to the exe.
  - **Known partial:** the Windows restart helper has only run in CI, never by us on real Windows (docs/updater.md audit). Never re-run a release to fix this (CLAUDE.md rule 12).
  - **More:** [updater.md](../../updater.md)

- [ ] **V-LA-008** Update channel and other editor versions
  - **Map:** 17.1.2, 18.5. **Where:** `OkaySpace.exe`, Settings page
  - **Steps:**
    1. In **Settings** open the **Update channel** combo and look at its choices (Latest and long-term support).
    2. Press **Manage versions** (next to "Other versions of the editor").
    3. On the **Versions** page install or open one other editor version.
  - **You should see (expected, not yet seen on Windows):** the combo offers the channels, and the Versions page lists installable editor versions; a version without a checksum is refused.
  - **Known partial:** the launcher itself is never downgraded by the channel choice (the setting text says so).
  - **More:** [launcher_versions.md](../../launcher_versions.md)

- [ ] **V-LA-009** Settings are remembered
  - **Map:** 17.1.5. **Where:** `OkaySpace.exe`, Settings page
  - **Steps:**
    1. In **Settings** change **UI scale** and toggle **Show progress bar**.
    2. Close and reopen the launcher.
    3. Press **Reset preferences** and confirm.
  - **You should see (expected, not yet seen on Windows):** your choices are still set after the restart (they live in `launcher.cfg` next to the exe); Reset puts theme, accent, UI scale, sorting and update settings back.
  - **Known partial:** some splash changes apply "the next time OkaySpace starts" (the page says so).
