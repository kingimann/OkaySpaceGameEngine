# Where to find each visual-script node

Every node in the Add Node menu, by the topic it sits in. Generated by `scripts/vs_category_report.py` from
the dump of `tests/test_vs_categories.cpp`; do not edit by hand. The rules (and how to place a new node) are in
[visual_scripting_naming.md](visual_scripting_naming.md). Search finds a node by its name, by its topic, and by
the old topic it used to sit in ([visual_script_category_audit.md](visual_script_category_audit.md)).

The name on the node comes first. A word in backticks is the type stored in a `.okayvs` file, or for an Actions step
its short name. **Basic**, **Intermediate** and **Advanced** are the level badges in the menu; a node with no mark is
Intermediate.
