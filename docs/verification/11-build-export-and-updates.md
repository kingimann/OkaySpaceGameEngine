# Verify: Build, export, updates and tooling

Build Settings, export, the release and update flow, tests and tooling.

Generated by `scripts/gen_verify_checklist.py` from the feature map and `docs/verification/steps/BX.md`; do not edit by hand. Read the [guide](README.md) first (legend and how to report).

Areas: 18, 19, 28, 33, 41, 56, 57, 58. Rows ids start `V-BX-`. `V-BX-S<area>` rows are smoke tests built from the map; `V-BX-NNN` rows have written steps.

- [ ] **V-BX-001** Build a game
  - **Map:** 18. **Where:** editor, Build Settings
  - **Steps:**
    1. Open a scene and choose **File > Build Settings...** (Ctrl+B), or press the Build button on the toolbar.
    2. Set the game name and the **Output folder**, then press **Build**.
    3. Open the output folder and start the `.exe`.
  - **You should see (expected, not yet seen on Windows):** a standalone game folder with an exe; the exe opens your scene and plays it.
  - **Known partial:** the player (`Tools\OkaySpacePlayer.exe`) must be next to the editor; the build never downloads one.
  - **More:** [build_mode.md](../../build_mode.md)

- [ ] **V-BX-002** Build & Run and zip
  - **Map:** 18. **Where:** editor, Build Settings
  - **Steps:**
    1. In **Build Settings** tick **Also create a .zip next to the folder** and **Open the output folder**.
    2. Press **Build & Run**.
  - **You should see (expected, not yet seen on Windows):** the game starts right after the build, a `.zip` appears next to the folder, and the folder opens in Explorer.
  - **Known partial:** Build & Run is for the desktop target only.

- [ ] **V-BX-003** Strip unused assets and encrypt data
  - **Map:** 18. **Where:** editor, Build Settings
  - **Steps:**
    1. Tick **Strip unused assets**, **Clean output folder** and **Encrypt game data**, then build.
    2. Open the shipped scene file in a text editor.
  - **You should see (expected, not yet seen on Windows):** only the used files are shipped; with Encrypt on, the scene is not readable text.
  - **Known partial:** encryption here is obfuscation, not secret keeping (the tooltip says so).
