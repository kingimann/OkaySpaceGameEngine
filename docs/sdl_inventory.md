# SDL2 inventory: what still calls SDL, where, and what covers it

Generated by `python3 scripts/sdl_inventory.py --ref 05feef3b --out docs/sdl_inventory.md` from commit `05feef3b` (2026-11-15). Do not edit by hand:
run the script again after moving call sites (a plain-language list of what to do next is in `docs/sdl_removal_plan.md`).

This page makes the remaining SDL2 dependency visible. `docs/platform_layer.md` is the design and the audit history of the seam;
this page is the current count, file by file, taken straight from the source.

## How it was counted

* Source: every `.cpp .hpp .h .cc .inl` file of the commit above that has an SDL word in code (43 files; 20 more mention SDL only in comments,
  see section 7). Docs, scripts and build files are not counted as code; build and CI files that name SDL2 are listed in section 6.
* Comments and string literals are removed first, so a word in a comment is not a use.
* **call** = an SDL name followed by `(`: a function call or a function-like macro. **ref** = every SDL word, calls included, so it also
  counts types (`SDL_Rect`), constants (`SDL_WINDOW_RESIZABLE`), event names (`SDL_KEYDOWN`), the integer typedefs (`Uint8`) and `#include`
  lines. A cell shows `calls / refs`. Calls are the numbers to read as "call sites"; refs show how much code mentions SDL at all.
* Words counted: `SDL_*`, `SDLK_*`, `KMOD_*`, the `AUDIO_*` format words, `Uint8..Sint64`, `ImGui_ImplSDL2_*`, `ImGui_ImplSDLRenderer2_*`.
  `SDL_DelayCompat` (a local helper in `engine/src/Net/PhotonTransport.cpp`) is not SDL and is skipped.
* All `#if` branches count (Windows-only and Emscripten-only code too). A macro that wraps an SDL call counts once, where it is written.
* **sdl2 backend** = `SdlBackend.cpp`, `SdlPainter.cpp` and `UIPainterSDL.hpp`: SDL on purpose, deleted together with SDL2. They are shown
  apart and are not part of "what the apps still call".
* "Used by" is by `#include` and CMake: a program's `.cpp` files (the ones its `CMakeLists.txt` names) plus `engine/src` and `okayui/src`,
  followed through `#include`. It over-approximates a little (one header name can resolve to more than one file).
* **Cross-check.** A plain `git grep -o -E '\b(SDL_\w+|SDLK_\w+|ImGui_ImplSDL\w+)[ \t]*\('` over the same commit (so comments and strings are counted too) gives launcher 743, editor 231, player 5, shared 29, okayui 45; the calls in the tables above for the same directories are launcher 743, editor 229, player 5, shared 25, okayui 44. The difference is the comments and strings.
* Not counted: Dear ImGui's own SDL backend source (it is fetched at configure time, not in this repository), SDL's own headers, the
  committed binaries `dist/SDL2.dll` and `dist/*.exe`, and anything reached only through a macro.

**The window caveat.** The launcher and the editor create their windows with `SDL_CreateWindow` and keep a raw `SDL_Window*`. Every `Window::`
method in `okay::platform` needs an `okay::platform::Window` object, which only `Backend::MakeWindow` makes (and the player is the only app
that uses it). So the HAVE rows for window geometry, visibility and the like are *reachable* only after the apps create or adopt their windows
through the seam. That is GAP `win.adopt` below.
