# Verify: Scene and components

Scenes, GameObjects, components, prefabs, assets, volumes and level tools.

Generated by `scripts/gen_verify_checklist.py` from the feature map and `docs/verification/steps/SC.md`; do not edit by hand. Read the [guide](README.md) first (legend and how to report).

Areas: 1, 20, 21, 36, 44, 45. Rows ids start `V-SC-`. `V-SC-S<area>` rows are smoke tests built from the map; `V-SC-NNN` rows have written steps.

- [ ] **V-SC-001** Create every kind of object from the GameObject menu
  - **Map:** 1, 36. **Where:** editor, GameObject menu
  - **Steps:**
    1. Open **GameObject > 3D Object** and add a **Cube**, a **Sphere** and a **Capsule**.
    2. Add a **Directional Light** from **GameObject > Light**, and **Create Camera**.
    3. Select each in the **Hierarchy** and look at the **Inspector**.
  - **You should see (expected, not yet seen on Windows):** each object appears in the Scene view and the Hierarchy; the Inspector shows its Transform and components.
  - **Known partial:** none known.

- [ ] **V-SC-002** Move, rotate and scale in the Inspector
  - **Map:** 1, 36. **Where:** editor, Inspector panel
  - **Steps:**
    1. Select a cube.
    2. Change its position, rotation and scale numbers in the **Inspector**.
    3. Press Ctrl+Z.
  - **You should see (expected, not yet seen on Windows):** the cube moves, turns and resizes as the numbers change; undo restores the old values.
  - **Known partial:** none known.

- [ ] **V-SC-003** Prefab: make, place, variant
  - **Map:** 21. **Where:** editor, Project panel
  - **Steps:**
    1. Make a prefab from an object (drag it from the Hierarchy into the **Project** panel).
    2. Right-click the `.okayprefab` file and choose **Place in Scene**.
    3. Right-click it again and choose **Create Variant**, then **Validate Prefab**.
  - **You should see (expected, not yet seen on Windows):** a second copy appears in the scene; a variant file is created; Validate reports no problems or lists them.
  - **Known partial:** map area 21 is marked planned in parts: expect gaps (nested prefab overrides, for example).
  - **More:** [prefabs.md](../../prefabs.md)

- [ ] **V-SC-006** Volumes (checkpoint, kill, force)
  - **Map:** 44, 1. **Where:** editor, GameObject menu
  - **Steps:**
    1. Open **GameObject > Volume** and pick a kind to draw (Checkpoint, Kill and so on), then drag a box in the Scene view.
    2. Make a player (**GameObject > Player > Third Person**) and a floor, and put the volume where the player will walk.
    3. Press Play and walk into the volume.
  - **You should see (expected, not yet seen on Windows):** a Kill volume sends the body back to its last checkpoint; a Checkpoint volume sets the respawn point. Volumes are drawn as coloured translucent shapes in the Scene view (toggle with **View > Scene Overlays > Volumes**).
  - **Known partial:** see docs/volumes.md for kinds that need other components (Ambience needs an Audio Source with a clip and Loop).
  - **More:** [volumes.md](../../volumes.md)
