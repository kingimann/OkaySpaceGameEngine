# Verify: Editor basics

The editor (`Tools\OkayEngine.exe`): menus, panels, Play, saving, undo, plugins, debugging tools.

Generated by `scripts/gen_verify_checklist.py` from the feature map and `docs/verification/steps/ED.md`; do not edit by hand. Read the [guide](README.md) first (legend and how to report).

Areas: 15, 22, 23, 24, 34, 54, 55. Rows ids start `V-ED-`. `V-ED-S<area>` rows are smoke tests built from the map; `V-ED-NNN` rows have written steps.

- [ ] **V-ED-001** Start the editor and show or hide panels
  - **Map:** 15. **Where:** `Tools\OkayEngine.exe` (or from the launcher)
  - **Steps:**
    1. Start `Tools\OkayEngine.exe`. The window shows docked panels and a toolbar.
    2. Open **View > Panels** and untick then tick **Hierarchy**, **Inspector**, **Project**, **Console**.
    3. Open **View > Panels > Game**.
  - **You should see (expected, not yet seen on Windows):** each panel disappears and comes back where it was; the Game panel opens as a tab.
  - **Known partial:** `editor/main.cpp` is one very large file with no automated window test; only `--selftest` runs in CI.

- [ ] **V-ED-002** New Project dialog
  - **Map:** 15, 25. **Where:** editor, File menu
  - **Steps:**
    1. Choose **File > New Project...**.
    2. Pick a template (for example **Third Person**), name it and create it.
    3. Look at the **Hierarchy** panel.
  - **You should see (expected, not yet seen on Windows):** a project folder is made, its scene opens and the Hierarchy lists the template's objects.
  - **Known partial:** the template list is shared with the launcher (`shared/ProjectCreate.hpp`).

- [ ] **V-ED-003** Play and Stop
  - **Map:** 15. **Where:** editor toolbar
  - **Steps:**
    1. Open a template scene (for example **File > New 3D Scene**).
    2. Press the triangle Play button on the toolbar, or press Ctrl+P. Hover it: the tooltip says "Play (Ctrl+P)".
    3. Press it again (tooltip "Stop (Ctrl+P)") or Ctrl+P.
  - **You should see (expected, not yet seen on Windows):** the scene runs in the Game panel; on Stop the scene returns to exactly what it was before Play (moved objects go back).
  - **Known partial:** Play is disabled while a prefab is open for editing (the tooltip says why).

- [ ] **V-ED-004** Save, open and recent scenes
  - **Map:** 15, 1. **Where:** editor, File menu
  - **Steps:**
    1. Make a change (for example **GameObject > 3D Object > Cube**) and press Ctrl+S (**Save Scene**; a new scene asks for a name via **Save Scene As...**).
    2. Choose **File > New 3D Scene** (it asks about unsaved changes first).
    3. Press Ctrl+O (**Open...**), paste the path of your scene, or press **Browse...**, and open it. Also try **Open Recent**.
  - **You should see (expected, not yet seen on Windows):** the saved cube is back after reopening; the title shows no unsaved mark after saving.
  - **Known partial:** `.okayscene` stores what the validator knows; unknown fields are dropped.

- [ ] **V-ED-005** Undo and redo
  - **Map:** 22, 15. **Where:** editor, Edit menu
  - **Steps:**
    1. Add a cube with **GameObject > 3D Object > Cube**, then delete it with **Delete Selected** (Del).
    2. Open the **Edit** menu: the first entry says what Ctrl+Z would undo. Press Ctrl+Z, twice.
    3. Press Ctrl+Y.
  - **You should see (expected, not yet seen on Windows):** the cube returns on the first undo and disappears on the second; redo brings it back. Undo and Redo are greyed when nothing can be undone.
  - **Known partial:** map area 22 (undo/redo and recovery) is listed as planned in parts; check which sub-areas say Works.
  - **More:** [editor_undo.md](../../editor_undo.md)
