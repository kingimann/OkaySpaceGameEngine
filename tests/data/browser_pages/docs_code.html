Configuration

The toolkit reads widgets.toml from the project folder. Every key is optional.

[window]
title  = "My app"
width  = 1280
height = 720

[theme]
accent = "#0969da"
Note: sizes are in logical pixels.
Warning: a missing theme file falls back to the default.
KeyTypeDefault
titlestring"App"
widthinteger800
heightinteger600

Press Ctrl + R to reload the file while the app runs.
