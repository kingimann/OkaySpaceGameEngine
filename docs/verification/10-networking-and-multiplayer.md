- [ ] **V-NW-001** Host and join on one PC (steps unverified)
  - **Map:** 16. **Where:** two copies of the editor
  - **Steps:** (steps unverified: could not be confirmed against the code)
    1. Choose **File > New Project...** and the **Multiplayer** template in two editor windows (or open the same project twice).
    2. In the first editor open the Multiplayer section (try **View > Panels > Services**, then **View > Panels > Net**), set a **Name** and press **Host Game**, then press Play.
    3. In the second editor type 127.0.0.1 into **Address**, press **Join**, then Play.
  - **You should see (expected, not yet seen on Windows):** both players appear in each other's game view; the connection status shows online.
  - **Known partial:** which panel holds the buttons was not confirmed; look in both. The map (16) lists Open notes for replication gaps (e.g. vehicle seats are not replicated).

- [ ] **V-NW-004** Anti-cheat in one click
  - **Map:** 39. **Where:** editor, multiplayer scene
  - **Steps:**
    1. Open a scene with a Network Manager (the **Multiplayer** template).
    2. Select the Network Manager, pick a preset (Casual co-op, Competitive, Economy game) and press **Add Anti-Cheat**. Or **Add Component > Anti-Cheat (one click, safe preset)**.
    3. Open **File > Build Settings...**, find the **Anti-cheat** box and read the checklist.
    4. Set **Anti-cheat** to **Report**.
  - **You should see (expected, not yet seen on Windows):** an anti-cheat config is added with the preset numbers; the checklist shows what is on and what is `[missing]`, with fix buttons.
  - **Known partial:** a detection engine starts in observe mode and never kicks; the libsodium-dependent parts run in a separate CI job; not independently reviewed (CLAUDE.md rule 18).
  - **More:** [anticheat_quickstart.md](../../anticheat_quickstart.md)

- [ ] **V-NW-005** Dedicated server export
  - **Map:** 16, 18. **Where:** editor, Build Settings
  - **Steps:**
    1. Open **File > Build Settings...** (Ctrl+B).
    2. Set the platform to Server, fill the **Server** page and press **Export**.
    3. Look in the output folder for `server.cfg` and `start-server.bat`.
  - **You should see (expected, not yet seen on Windows):** an output folder with the server runtime, `server.cfg` and start scripts.
  - **Known partial:** the Windows server was not run by us; Linux server export fetches a runtime from GitHub with only a size check (docs/updater.md known gaps).
  - **More:** [dedicated-server.md](../../dedicated-server.md)
