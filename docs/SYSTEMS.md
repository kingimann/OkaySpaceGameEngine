# Systems

Generated from the `System:` lines of the feature map pages by `scripts/gen_feature_map.py`; do not edit.
Back to the [feature map](FEATURE_MAP.md).

This is **the one list of systems** (the registry). A **system** is a named part of OkaySpace that does one job from start to end (Physics, Save Games, OkayScript, the Launcher Updater). Each system has one official name, one home folder, one entry file, one doc and one owner lane, and is made of one or more sub-areas of the feature map.

**Before you make anything**, look here: `python3 scripts/find_existing.py <words>` searches the names and the old names below first. If a system does the job, add on to it (CLAUDE.md rules 19c, 19d and 19e; [docs/process/no_duplicates.md](process/no_duplicates.md)).

- **Home** is the folder (or files) that hold the system's own code; new code for it goes there. An editor window or a component for it is not a second home.
- **Entry** is the file to open first: the main header, program or script.
- **Doc** is the one guide for it. **Lane** is who owns the entry file (`docs/lanes.json`).
- **Also called** lists old and other names it has had, frozen names (scene keys, env vars, CMake options, class names) and the third-party part it replaces, so a search for any of them lands here. Use the official name in new code, docs and messages (naming rule: [engine/architecture.md](engine/architecture.md#naming)).
- **Status** comes from the sub-areas' Status lines (Works, Partial, Basic, Planned, In flight); a system made of sub-areas in different states lists how many are in each.
- **Feature map** links every sub-area that is part of it; the first one is the one that describes it.
- To name or change a system, edit the `- **System:**` line of a sub-area in `docs/feature_map/` (format in `docs/feature_map/README.md`), then run `python3 scripts/gen_feature_map.py`.
